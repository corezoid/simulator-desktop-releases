# Changelog

All published releases of the Simulator.Company desktop application, newest
first. Release notes on the [releases page](https://github.com/corezoid/simulator-desktop-releases/releases)
carry the same content per release.

## v0.12.7 — Linux, Windows

First release published on GitHub. Linux `.deb`/`.rpm` for x64 and arm64,
Windows Squirrel installers for x64 and arm64. Linux assets are also available
as torrents with a webseed. These are the same builds served by
[app.simulator.company](https://app.simulator.company).

## v0.12.4 — macOS

First macOS release published on GitHub: `.dmg` for Apple Silicon and Intel.
Same builds as the application's own update channel.
