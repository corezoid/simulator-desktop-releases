# Changelog

All published releases of the Simulator.Company desktop application, newest
first. Release notes on the [releases page](https://github.com/corezoid/simulator-desktop-releases/releases)
carry the same content per release.

## v0.12.7

Current release for Linux and Windows: `.deb`/`.rpm` for x64 and arm64, Squirrel
installers for Windows x64 and arm64, Linux assets also as torrents with a
webseed. Same builds as the application's own update channel at
[app.simulator.company](https://app.simulator.company). First release published
on GitHub.

## v0.12.4

Full snapshot of the earlier version — all platforms, including the current
macOS builds (`.dmg` for Apple Silicon and Intel). macOS releases on its own
cadence, so this tag holds the newest macOS build until the next one.
