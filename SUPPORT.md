# Support

**Issues are disabled in this repository.** It exists to distribute builds, not
to track work, and an issue opened here would be read by nobody.

| What you have | Where it goes |
|---|---|
| A question about using the application | **support@corezoid.com** |
| A bug, a crash, an install that never finishes | **support@corezoid.com**, with the details below |
| A security vulnerability | **support@corezoid.com** with a `[SECURITY]` subject — see [SECURITY.md](SECURITY.md), never a public channel |
| A question about Corezoid or Simulator themselves | The product's own support and [documentation](https://doc.corezoid.com), not this repository |
| Mobile applications | The stores' feedback channels, or support@corezoid.com |

---

## Sending a useful report

Include:

- the application version (About screen, or the installer file name);
- your operating system and processor (Apple Silicon / Intel / Windows / Linux);
- what you did, what you expected, what happened instead;
- if the local platform is involved — the report the application saves from
  *Downloads → Save a report*, which contains the failure stage with home paths
  and token-like values already redacted.

## What we cannot help with

- Modifying the application or its bundled components.
- Machines below the system requirements in [INSTALL.md](INSTALL.md) — the
  built-in check in *Downloads* names the number that is short, and that number
  is the answer.
